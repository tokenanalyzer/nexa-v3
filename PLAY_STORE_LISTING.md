## Full Description (max 4000 chars)
NEXA AI is your autonomous AI content strategist — powered by Google Gemini 2.5 Flash, Groq Llama, and SambaNova, working together to generate viral, platform-optimized social media content in seconds.

Whether you're a creator, brand, freelancer, or marketer — NEXA AI helps you produce high-quality content for Instagram, YouTube, Twitter/X, LinkedIn, TikTok, and WhatsApp with zero effort.

**🤖 AGENT SWARM — 3 AI Agents Working in Parallel**
Three specialized AI agents collaborate simultaneously:
• Gemini (Content Architect) — creative posts, brand voice, visual prompts
• Groq (Viral Scout) — trending hooks, hashtags, best posting times
• SambaNova (Growth Strategist) — SEO angles, engagement psychology

**🔥 FORGE — Content Generator**
• Manual Mode: Generate platform-specific content instantly
• Autopilot Mode: Full 3-day content calendar with viral score
• Swarm Mode: All 3 agents generate simultaneously
• Content Tone Matrix: Professional, Gen-Z, Sarcastic, Inspirational
• Multi-language: English, Hindi, Spanish, Hinglish
• Trend Scout: Live trending topics across 10 niches
• Hashtag Heatmap: Tap-to-copy hashtag sets
• A/B Hook Tester: Compare two hooks with psychological analysis
• Best Time Predictor: AI-powered optimal posting windows
• Visual Prompt Generator: Midjourney/DALL-E ready image prompts
• Viral Thread Builder: Complete 10-tweet thread with character counts

**🧠 INTEL — AI Chat Assistant**
Full-memory AI chat with real-time streaming. Ask anything about content strategy, trends, or platform growth. Persistent conversation history across sessions.

**🗄️ VAULT — Content Storage**
Save, organize, and schedule your best content. Search, share, or delete anytime. Complete Swarm History with agent timing stats.

**🔒 Privacy First**
• No account required
• API keys stored locally on your device only
• Generated content never leaves your device
• Zero data collection

## What to do before submitting:

1. **Host Privacy Policy:**
   - Go to GitHub repo → Settings → Pages → Enable GitHub Pages (main branch)
   - Privacy Policy will be live at: https://tokenanalyzer.github.io/nexa-v3/privacy-policy.html

2. **Build Production APK/AAB:**
   ```bash
   eas build --platform android --profile production
   ```
   (Production profile builds AAB which Play Store requires)

3. **Play Store Console steps:**
   - Create app → Package name: com.nexa.ai
   - Upload AAB file
   - Fill description from this document
   - Add screenshots (min 2, recommended 8)
   - Set Privacy Policy URL
   - Complete Data Safety form (all No/minimal)
   - Complete Content Rating questionnaire
   - Set price: Free
   - Target countries: Select all or specific
   - Submit for review (~3-7 days)
